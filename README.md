# 🎮 Tic Tac Toe Game (HTML, CSS, JavaScript)

This is a simple **Tic Tac Toe** game built using **HTML**, **CSS**, and **Vanilla JavaScript**. It allows two players to play against each other on the same device in a responsive and interactive UI.

---

## 🚀 Features

- Two-player mode (X and O)
- Winner detection
- Draw detection
- Game reset button
- Responsive design for desktop and mobile

---

## 🛠️ Technologies Used

- **HTML5** – Structure
- **CSS3** – Styling
- **JavaScript (ES6)** – Logic
